# Project Architecture

## 1. Frontend

The frontend is responsible for all user-facing pages and interactions.

### Responsibilities
- Landing page
- Tutor listings
- Subject search
- Booking request form
- Authentication pages
- Dashboard views

### Technologies
- HTML
- CSS
- JavaScript

## 2. Backend

The backend provides the API that powers frontend functionality.

### Responsibilities
- User authentication
- Tutor data retrieval
- Booking management
- Search and filtering logic
- Business logic for feature workflows

### Technologies
- Node.js
- Express.js

## 3. Data model

Core entities:
- User
- Tutor
- Student
- Booking
- Review
- Subject

## 4. MVP scope

The basic version includes:
- homepage
- tutor cards
- tutor search form
- basic API endpoints
- tutor data source

## 5. Next phases

- user accounts
- tutor profiles
- admin features
- bookings and scheduling
- reviews
- payment processing
- notifications
